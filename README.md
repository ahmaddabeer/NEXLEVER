# Nexlevr – Android App

A UI-focused Android application inspired by the official Nexlevr website, developed as part of an internship task.

The main objective of this project was to recreate the Nexlevr website experience in an Android application with a clean, modern, and user-friendly interface.

## 📱 Project Overview

Nexlevr is a simple Android application that represents the Nexlevr website experience.

The app focuses mainly on UI design and navigation. Important sections and actions are connected to their respective pages on the official Nexlevr website. When users click on these elements, they are redirected to the corresponding website page.

## ✨ Features

- Clean and modern user interface.
- Website-inspired Android app design.
- Smooth scrolling and UI navigation.
- Clickable sections and interactive elements.
- Direct links to the official Nexlevr website.
- Simple and user-friendly experience.

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **IDE:** Android Studio
- **Platform:** Android

## 🚀 How to Clone and Run

Follow these steps to run the project locally:

**1. Clone the repository**

```bash
git clone https://github.com/ahmaddabeer/NEXLEVER.git
```

**2. Open the project**

- Open Android Studio.
- Select `Open`.
- Choose the cloned project folder.

**3. Sync Gradle**

Wait for Android Studio to complete the Gradle sync.

**4. Run the application**

- Connect an Android device or start an emulator.
- Click the Run button in Android Studio.

## 📌 Project Scope

This project was developed primarily to demonstrate Android UI development and website-inspired design.

It is not intended to be a fully functional replica of the original website. Most of the important actions redirect users to the official Nexlevr website through external links.
